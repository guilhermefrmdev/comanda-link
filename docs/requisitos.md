# Requisitos do Projeto 2

| #RF | Nome RF | Descrição RF |
|-----|---------|--------------|
| RF01 | Registrar Pedido | O cliente registra um pedido vinculado a uma mesa. |
| RF02 | Detalhar Itens do Pedido | O pedido contém itens, quantidades e observações (ex: "sem salada"). |
| RF03 | Consultar cardápio e disponibilidade | O sistema consulta o cardápio e a disponibilidade dos itens. |
| RF04 | Exibir pedidos na cozinha | O pedido aparece para a cozinha, pela ordem de chegada. |
| RF05 | Atualizar status do pedido | O cozinheiro atualiza o status: recebido → em preparo → pronto. |
| RF06 | Notificar pedido pronto | O garçom/cliente é notificado quando o pedido fica pronto. |
| RF07 | Editar/Cancelar pedido | Permitir editar ou cancelar o pedido antes de entrar em preparo. |
| RF08 | Adicionar itens ao pedido | Permitir adicionar itens a um pedido já aberto. |
| RF09 | Consultar histórico | Consultar o histórico e o status da mesa. |
| RF10 | Gerenciar cardápio | O administrador gerencia o cardápio (adicionar, editar, desativar itens). |
| RF11 | Fechar conta da mesa | Fechar a conta da mesa. |
